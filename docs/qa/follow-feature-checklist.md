# Follow Feature QA Checklist

## 1. 로그인 상태

- [ ] 비로그인 사용자가 상품 상세에서 `팔로우` 버튼 클릭 시 로그인 안내가 노출된다.
- [ ] 로그인 사용자가 타인 상점에서 `팔로우` 버튼을 누르면 `팔로잉`으로 바뀐다.
- [ ] `팔로잉` 버튼을 다시 누르면 `팔로우`로 복귀한다.
- [ ] 본인 상점에서는 팔로우 버튼이 노출되지 않는다.

## 2. 카운트 동기화

- [ ] 팔로우 직후 판매자 카드의 `팔로워` 수가 즉시 반영된다.
- [ ] 언팔로우 직후 판매자 카드의 `팔로워` 수가 즉시 반영된다.
- [ ] 마이페이지의 `팔로워`, `팔로잉` 카운트가 현재 계정 데이터와 일치한다.

## 3. 목록 모달

- [ ] 상품 상세의 `팔로워` 클릭 시 팔로워 목록 모달이 열린다.
- [ ] 상품 상세의 `팔로잉` 클릭 시 팔로잉 목록 모달이 열린다.
- [ ] 마이페이지의 `팔로워` 클릭 시 팔로워 목록 모달이 열린다.
- [ ] 마이페이지의 `팔로잉` 클릭 시 팔로잉 목록 모달이 열린다.
- [ ] 목록이 없을 때 빈 상태 문구가 올바르게 보인다.
- [ ] 모달 배경 클릭 또는 닫기 버튼으로 모달이 닫힌다.

## 4. 데이터/네트워크 시나리오

- [ ] 새 계정 가입 시 `followers`, `following`이 빈 배열로 초기화된다.
- [ ] 회원 탈퇴 시 다른 유저의 팔로우 관계에서 탈퇴 계정이 제거된다.
- [ ] 목록 API 실패 시 사용자에게 오류 안내가 보이고 앱이 깨지지 않는다.
- [ ] 팔로우 토글 API 실패 시 사용자에게 오류 안내가 보이고 기존 상태가 유지된다.

## 5. 회귀 확인

- [ ] 찜 기능(`wish`)이 기존과 동일하게 동작한다.
- [ ] 로그인/로그아웃/회원정보 수정 흐름이 기존과 동일하게 동작한다.
- [ ] 빌드(`pnpm build`)가 성공한다.
